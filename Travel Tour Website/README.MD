# Farside — Travel Booking Website
A responsive travel agency landing page built with HTML, CSS and Bootstrap 5. Designed around a "boarding pass" visual concept — package cards, ticket stubs and postcard-style galleries — to give the booking experience a travel-document feel.

## Features

- 🎫 Boarding-pass styled package cards with routes, ratings and fares
- 📮 Postcard-style trending destinations strip
- 📝 Trip booking form (destination, travelers, dates, notes)
- 🖼️ Photo gallery of destinations
- 📱 Fully responsive (mobile, tablet, desktop)
- ✨ Smooth scroll navigation with custom easing
- 🌍 Animated destination text in the hero section

## Built With

- HTML5
- CSS3 (custom properties, flexbox, grid)
- [Bootstrap 5](https://getbootstrap.com/) — layout grid & components
- [Font Awesome](https://fontawesome.com/) — icons
- Google Fonts — Fraunces, Work Sans, IBM Plex Mono

## Running Locally

No build step required — it's a static site.

```bash
git clone https://github.com/shfatime1/website.git
cd website
```

Then just open `index.html` in your browser, or serve it locally:

```bash
python3 -m http.server 8000
```

and visit `http://localhost:8000`.
